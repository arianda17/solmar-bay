Solmar Bay is an original open-world crime game: a sun-soaked coastal city to explore on foot and by car, with traffic, pedestrians, a five-star wanted system, police chases, three weapons, and six story missions. Built with three.js, it runs entirely in the browser from its own files, with no network at runtime. Keyboard + mouse.

## Run it

```sh
node main.ts
```

Then open the game in your browser and play.
